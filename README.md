# 基于多智能体协同的混合量化交易回测系统

本项目是一个融合了**传统技术指标分析**、**大语言模型（LLM）基本面情感分析**、**计算机视觉（CNN）K线形态识别**以及**多智能体（Multi-Agent）协同决策**的混合量化交易回测系统。

系统通过多个专业化智能体（Agent）分别评估市场的技术面、基本面和风险度，最终由“首席决策官”（Meta-Decision Agent）整合所有维度的报告，做出交易立场裁决（`BULLISH` / `BULLISH_HOLD` / `BEARISH` / `NEUTRAL`），并在历史数据中进行双向（多头与空头）回测验证。

---

## 系统架构

在每一个回测时间步，系统执行以下研判管线：

```text
                    +------------------------+
                    |    历史行情与新闻数据   |
                    +-----------+------------+
                                |
         +----------------------+----------------------+
         |                      |                      |
         v                      v                      v
+-----------------+    +-----------------+    +-----------------+
| 趋势温度智能体   |    | 基本面新闻智能体 |    |   风控智能体     |
| (或CNN视觉智能体)|    | (本地/API RAG)  |    | (回撤与止损监控) |
+--------+--------+    +--------+--------+    +--------+--------+
         |                      |                      |
         | (技术面报告)          | (基本面情感报告)      | (风控指令报告)
         +--------------+-------+----------------------+
                        |
                        v
            +-----------------------+
            |      首席决策官        |  <-- DeepSeek-Chat
            | (Meta-Decision Agent) |
            +-----------+-----------+
                        | (JSON: BULLISH / BULLISH_HOLD / BEARISH / NEUTRAL)
                        v
            +-----------------------+
            |       回测引擎         |  <-- 双向持仓、移动追踪止盈、
            |   (Backtest Engine)   |      夏普/卡玛/盈亏比绩效评估
            +-----------------------+
```

## 核心智能体与信号体系

### 1. 信号状态定义 (Market Stance)
* `BULLISH`: 强烈看涨，主升浪确立，执行建立多头头寸或继续持有多头。
* `BULLISH_HOLD`: 多头良性回调或中继支撑，持有多头者拿住，空仓者不追高。
* `BEARISH`: 破位看跌，空头主导，执行建立空头头寸。
* `NEUTRAL`: 中性震荡/风控避险，平掉所有头寸，回归现金防御状态。

### 2. 智能体分工
* **技术面分析师 (`TrendTemperatureAgent` / `CNNVisionAgent`)**：
  * `TrendTemperatureAgent`：综合 EMA 均线多头排列与唐奇安通道位置，给出 0-100 的温度评分与形态研判。
  * `CNNVisionAgent`：基于预训练的卷积神经网络对时间窗口内的 K 线图进行图像形态分类。
* **基本面新闻分析师 (`FundamentalNewsAgent`)**：
  基于检索增强生成（RAG），检索当前交易日前 30 天内发生的 SEC 官方归档与重大财务披露，消除前瞻偏差后提取事实并评估情绪。
* **风控管理员 (`RiskControlAgent`)**：
  监控持仓以来的最大回撤与硬性止损线（默认 10%），防范单笔极端损失。
* **首席决策官 (`MetaDecisionAgent`)**：
  基于 DeepSeek 驱动，整合三方报告执行严格的优先级决策（风控一票否决制）。

## 快速上手

### 1. 环境安装
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
在根目录创建 `.env` 文件：
```ini
DEEPSEEK_API_KEY="您的_DEEPSEEK_API_KEY"
```

### 3. 下载历史数据与情报库
```bash
python download_data.py
python download_news.py
```

### 4. 运行回测
```bash
python main.py
```
